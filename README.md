# InstantSnap

InstantSnapは、ショートカットキーやミニウィンドウから素早くスクリーンショットを撮影できるWindows向けアプリケーションです。
普段は軽量なSwing製ミニウィンドウとして常駐し、必要なときだけJavaFX製の設定画面を別プロセスで起動します。

## 主な機能

- アクティブウィンドウ、カーソルのある画面、メイン画面、全画面の撮影
- マウス操作による範囲選択撮影
- グローバルショートカットキーからの撮影と範囲選択
- PNG、JPEG、BMP、GIF形式での画像保存
- クリップボードへの画像コピー
- 撮影後に画像またはペイントを開く操作
- 撮影結果のデスクトップ通知と通知からの保存先表示
- 撮影音、通知音、マウスカーソル表示の切り替え
- InstantSnapのウィンドウを撮影画像へ含めるかどうかの切り替え
- デフォルト、ダーク、絵本の3テーマ
- 日本語、英語、中国語（簡体字）、韓国語、フランス語、スペイン語、ロシア語、ドイツ語、ポルトガル語（ブラジル）に対応

## 使い方

1. `InstantSnap.exe`を起動します。
2. ミニウィンドウの撮影範囲を選択します。
3. 撮影ボタン、範囲選択ボタン、または設定したショートカットキーから撮影します。
4. 保存先やショートカットキーなどを変更する場合は、歯車の設定ボタンを押します。

設定画面を閉じてもInstantSnapの常駐とショートカットキー監視は継続します。アプリを終了する場合はミニウィンドウを閉じ、表示される確認画面から終了してください。

### 範囲選択撮影

範囲を確定した直後に自動撮影するか、確定状態を挟んでから撮影するかを設定できます。撮影後も範囲選択を続けるか、自動的に範囲選択モードを終了するかも選択できます。

### 設定ファイル

設定内容は`config.properties`へ保存されます。通常は設定画面から変更してください。ファイルを直接編集することもでき、設定画面から保存した場合も標準テンプレートのコメントと項目順は維持されます。不正な値は起動時に既定値へフォールバックします。

## 動作環境

- Windows
- 配布用アプリにはJavaランタイムが同梱されるため、利用者によるJDKのインストールは不要です。

高解像度画面や複数画面の撮影、クリップボードへのコピーでは、一時的にメモリ使用量が増える場合があります。

## ソースからのビルド

### 必要な環境

- JDK 21（`jpackage`を含むもの）
- PowerShell

`JAVA_HOME`へJDK 21を設定した状態で、プロジェクトのルートから次を実行します。

```powershell
.\build-app-image.ps1
```

JDKを明示する場合は`-JdkPath`を指定します。

```powershell
.\build-app-image.ps1 -JdkPath 'C:\path\to\jdk-21'
```

ビルドではMavenによるコンパイルとパッケージング、ProGuardによる難読化、`jpackage`によるWindowsアプリイメージ生成を順番に行います。

生成された実行ファイルは次の場所に出力されます。

```text
exe/InstantSnap/InstantSnap.exe
```

配布する場合は、実行ファイルだけでなく`exe/InstantSnap`フォルダ全体が必要です。生成先に同名フォルダがある場合、ビルドスクリプトは上書きせずに終了します。別の生成先を使用する場合は次のように指定できます。

```powershell
.\build-app-image.ps1 -Destination 'target/app-image'
```

JARのみをビルドする場合は次を実行します。

```powershell
.\mvnw.cmd clean package -DskipTests
```

難読化済みJARは`target/jpackage-input`へ配置されます。

## アプリケーション構成

生成されるexeは1つです。通常起動ではSwing製ミニウィンドウと撮影監視を開始します。設定ボタンを押すと、同じexeを`--settings`オプション付きで別プロセス起動し、JavaFX製設定画面を表示します。

ビルドスクリプトは常駐利用向けのJVMオプションもアプリイメージへ設定します。JARだけを再ビルドしても既存exeのJVMオプションは更新されないため、配布用アプリへ反映する場合はアプリイメージも再生成してください。
