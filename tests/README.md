# UIの回帰検証

JDK 21以降をPATHに設定し、リポジトリ直下から次を実行します。Mavenの依存関係は取得済みである必要があります。

```powershell
.\tests\run-ui-probes.ps1
```

検証中は範囲選択画面とミニウィンドウが短時間表示されます。撮影・設定保存・クリップボード操作は行いません。

- 範囲選択：2モニターで200回交互に切り替え、同じ2画面が再利用されることを確認します。選択中・確定済みの切り替え抑止、撮影座標、作成失敗時の元画面維持、通知回数、終了時の全画面・タイマー解放も検証します。1モニターの場合、モニター間の項目はスキップします。
- ミニウィンドウ：OS標準Look and Feelで、各操作部品への実際のフォーカス移動と枠の描画を確認します。Tab巡回、枠の余白、Enterによる選択欄の開閉、テーマの往復、無効な部品が巡回対象から外れることも検証します。

手動確認では、範囲選択の待機中にモニターを交互に移動し、両方の画面を一度表示した後もメモリが切り替えのたびに増え続けないことを確認します。モニターごとの最初の表示では描画領域を確保します。

ミニウィンドウはデフォルトテーマでTab・Shift+Tabを使い、言語選択、撮影範囲選択、保存先・通知アイコンを含む各部品のフォーカス位置が枠で見えることを確認します。
